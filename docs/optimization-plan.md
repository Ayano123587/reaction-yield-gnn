# Controlled optimization plan

The2-epoch execution is an exploratory mechanics smoke, not a final model or independent test claim. Its aggregate test metrics were seen. The subsequent optimization keeps the same test cohort fixed and excludes all test predictions from selection. A separately sourced C-N high-throughput cohort will be evaluated only after final model choice to provide a genuinely separate source test; its assay-yield labels differ from ELN outcomes and interpretation must reflect that shift.

Falsifiable hypothesis: role-specific pooling reduces dilution by bulky catalyst graphs and lowers unseen-substrate-scaffold validation MAE compared with global pooling. Main ablation holds width 48, layers 3 and learning rate.001 fixed, changing only pooling. Two additional configurations independently change width to 96 and learning rate to.003. All configurations use three scaffold-disjoint development folds, seed42, batch24, AdamW, max60 epochs and early stopping after10 epochs without improvement (minimum20 executed). Score is mean fold MAE. A fixed3-point forest min-leaf grid1/3/8 is scored on the same folds.

Final GNN configuration and refit epoch count (median best epoch across folds) are selected only on development validation. Refit uses all610 development rows. The selected forest is likewise refit on all development data. Both and a train-only median constant are finally scored on the fixed130-row test. No test-driven reruns or tuning are permitted in this experiment. Source-transfer scoring follows final selection.

Compute estimate: initial2-epoch smoke including graph construction/baselines took8.6seconds. Four GNN configurations times three folds with early stopping should fit approximately10–30 CPU minutes at two threads; no GPU allocation or costs. Preserve per-trial progress as it completes. Stop on nonfinite loss or invalid split/outputs; completed validation trials remain reviewable. This is a bounded controlled optimization, not proof of a globally optimal score.

Additional dataset investigation: official ORD dataset805ad863feef48579d95d86a728035f4 contains50,688 Pd/Ni/CuC-N couplings but only2 amines and4 aryl halides. It is unsuitable as an indiscriminate50k-row augmentation for diverse-scaffold ELN yield prediction: the narrow substrates would dominate groups, and assay versus isolated yield semantics differ. It is retained as a separate transfer evaluation rather than silently merged.
